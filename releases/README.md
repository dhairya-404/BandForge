# Tesso Extension Releases

Ready-to-install packages for Google Chrome, Brave, Microsoft Edge, and Opera:

### 1. Pre-Packaged Extension (`.crx`)

- **Download:** [`tesso.crx`](https://github.com/dhairya-404/Tesso/raw/main/releases/tesso.crx)
- **How to Install (Brave & Chrome):**
  1. Open `brave://extensions` or `chrome://extensions`.
  2. Toggle on **Developer mode** in the top-right corner.
  3. Drag and drop the downloaded `tesso.crx` file into the extensions window.
  4. Click **Add extension**.
  - The extension is now permanently installed!

### 2. Store-Ready Distribution ZIP (`.zip`)

- **Download:** [`tesso-chrome-extension.zip`](https://github.com/dhairya-404/Tesso/raw/main/releases/tesso-chrome-extension.zip)
- Ready for 1-click upload to the [Microsoft Edge Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview) or [Chrome Web Store](https://chrome.google.com/webstore/devconsole).
